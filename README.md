# RuhRank 🏆

**Practice • Compete • Rank**

Free competitive exam preparation app for students — SSC, Railway, Banking, Bihar Police, BPSC, Defence, CTET/STET and more.

- 📝 Practice mode (subject-wise, topic-wise, timed)
- 🧪 Real exam-like mock tests with negative marking
- 🏆 Leaderboard & daily challenges
- 📰 Current affairs & previous year questions
- 100% free, by Hasnain

**Download:** https://github.com/Ruhvibes/ruhrank/releases/download/v1/RuhRank.apk
